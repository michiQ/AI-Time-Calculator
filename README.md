# Michiko Quinones AI Time Calculator

Open `index.html` locally or publish it using GitHub Pages (Deploy from branch, root). No build step.

## Public company lookup

Search US public companies by name or ticker using SEC public data. Choose the company and click **Use revenue and margin** to populate the optional profitability inputs. The lookup uses browser-side requests to SEC endpoints. **SEC CORS or rate restrictions may block browser requests**; manual entry remains available. Figures are from reported annual XBRL tags and must be verified against filings. Company-wide operating expenses are not automatically treated as in-scope spend. No API key is required.
