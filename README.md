# Michiko Quinones AI Time Calculator

A standalone, responsive calculator exploring the relationship between AI disruption horizons, organizational pivot speed, and operating friction.

## Publish on GitHub Pages

1. Create a new public GitHub repository, for example `ai-time-calculator`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, `main`, and `/ (root)`; save.
5. Open the GitHub Pages URL shown in Settings after deployment.

No packages, build tools, accounts, or API keys are required. The calculator runs entirely in the browser.

## Methodology

This is a scenario model, not an empirical forecast. Driver choices map to illustrative months and friction percentages. See the methodology disclosure inside the webpage.
